## 2026-09-18 主题对齐 filll.cn 品牌

- **操作**：抓取 `https://www.filll.cn/css/filll.css`，提取其品牌设计系统，据以重写 `index.html` 的视觉主题。
- **设计系统来源**：filll.cn 采用「Claude / Anthropic 暖纸色主题」，关键变量如下：
  - 背景 `--bg:#F0EEE6`（暖奶油纸色）、卡片 `--bg-panel:#FBF9F3`（暖白）、次级 `--bg-soft:#E7E2D6`
  - 单一珊瑚/赤陶强调色：`#CC785C`（珊瑚）、`#B85F43`（赤陶）
  - 文字暖墨色：`#141414` / `#6E6A60` / `#9C978B`
  - 字体：Newsreader（衬线标题）+ Inter（正文）+ IBM Plex Mono（数据/编号）
  - 圆角 14px、毛玻璃导航、点阵背景纹理、衬线大标题
- **改动内容**：将原蓝紫渐变主题整体替换为暖纸色 + 珊瑚强调色，导航/卡片/按钮/表格/页脚全部按 filll.css 变量重写；功能与交互保持不变。
- **结论**：字体经 Google Fonts 加载，加载失败时自动降级为系统衬线/无衬线/等宽字体，不影响可用性。

## 2026-09-18 静态化重构

- **操作**：运行 `Script1-Export-DB-To-JSON-V1.R`，将 `GeneConvertToCS.db` 导出为按源版本拆分的 JSON 映射文件。
- **结果**：生成 5 个映射文件（`data/` 下），去重后键数如下：

| 源版本 | 去重后键数 | 去重前记录数 |
| --- | --- | --- |
| IAAS | 219,721 | 255,174 |
| CS3G | 106,914 | 205,379 |
| CAU | 152,163 | 251,847 |
| CS2G | 106,913 | 205,379 |
| CS1G | 103,171 | 199,166 |

- **结论**：同一源版本存在重复 ID（去重前多于去重后），导出时保留首次出现（与原 Shiny 版"取第 1 行"一致）。
- **新增文件**：`index.html`（静态应用）、`Script1-Export-DB-To-JSON-V1.R`、`data/*.json`。

## 项目背景

- 原应用为 R Shiny 实现的小麦中国春基因 ID 批量转换工具，数据存于 SQLite（`gene_convert` 表，264,504 行）。
- 重构目标：去掉 Shiny 后端，改为纯静态 HTML 应用，保留转换、示例数据、结果表格、CSV 下载、`?key=wangzhen` 授权与 51.la 统计等全部功能。
