使用说明

本工具用于小麦中国春参考基因组基因 ID 的在线批量转换，支持 IAAS、CAU、CS1G、CS2G、CS3G 等多个版本之间的相互映射。全部计算在浏览器本地完成，数据无需上传服务器，安全便捷。

使用方法：

  1. 将待转换的基因 ID 整理为一列（每行一个），复制粘贴到下方输入框；
  2. 选择原始基因 ID 版本与目标基因 ID 版本；
  3. 点击「开始转换」，在结果表格中搜索、排序，并导出 CSV 或 Excel 文件。
